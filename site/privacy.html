Privacy

Current website practices · Updated October 17, 2026

Reading this website

You can read World Desk without an account. The site currently has no reader signup, checkout, or newsletter email subscription form. It does not ask readers for payment information.

Hosting and server logs

World Desk is hosted on DigitalOcean. When a browser requests a page, the hosting server handles network information needed to deliver it. Standard server logs may include your IP address, request time and path, response status, browser information, and referring page. These records support operation, troubleshooting, and security.

The current server rotates its web logs daily and keeps up to 14 rotated log files. This describes the website server's configuration; hosting-provider records and retention are governed separately by DigitalOcean's privacy policy.

Cookies, analytics, and advertising

The current site does not set its own tracking cookies, run third-party analytics, or load an active advertising network. Advertising integration is disabled. This notice and any required consent controls must be updated before advertising or analytics is enabled.

Links to other publishers

Story links take you to independent websites with their own privacy and advertising practices. World Desk does not control those sites. Review their policies before providing personal information.

Changes

The date above identifies this notice's current version. Changes to data collection, advertising, or reader services will be reflected here.
